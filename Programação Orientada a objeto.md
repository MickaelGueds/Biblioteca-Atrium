Necessario lembrar de alguns conceitos:

Classes -> é o molde, modelo de algo as coisas que tem, exemplo um carro é uma classe, nao o carro em si, a classe é o modelo, no caso ter 4 rodas e etc...

Instance -> é um objeto criado a partir de uma classe,a instancia,é de fato o carro, é tipo o hb20

Inheritance(Herença) -> quando uma classe filha aproveita o comportamento do pai, aqui no caso, imagina classe de mamiferos, uma classe "Gato" consegue pegar caracteristicas de mamiferos

Encapsulation -> proteger dados internos, como podem ser acessados ou modificadosm é aqui que temos metodos pra controlar
